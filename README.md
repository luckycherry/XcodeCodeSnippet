# setup_tools.sh 自动化注入脚本

在终端项目根目录执行 ./setup_tools.sh

# Xcode CodeSnippet
Xcode 快捷代码片段 (一个文件对应一个片段)

目录在:
~/Library/Developer/Xcode/UserData/CodeSnippets/

退出xcdoe 后 终端执行
rm -rf ~/Library/Caches/com.apple.dt.Xcode
重新打开生效
